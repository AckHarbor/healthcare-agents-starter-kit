# Contributing

Thanks for your interest. We are **not accepting outside pull requests, patches or code contributions for now**.
Pull requests from outside contributors will be closed without review.

You are welcome to fork and change the kit under the Apache License 2.0 (see LICENSE and NOTICE). If you
redistribute a changed version, rename it and don't imply our endorsement.

Found a bug or a security problem? Email support@ackharbor.com. Never include real patient data (PHI).
